# Расписание занятий

REST API для управления расписанием: группы, преподаватели, предметы, занятия.

## Стек

- Go 1.27, `net/http` (стандартный `ServeMux`)
- PostgreSQL 16
- `pgx/v5` (`pgxpool`)
- Docker Compose

## Запуск

```bash
docker compose up -d
go run .
```

Сервер слушает `http://localhost:8080`.

Adminer (веб-интерфейс к базе): `http://localhost:8081`
— система `PostgreSQL`, сервер `db`, пользователь `postgres`, пароль `postgres`, база `schedule`.

## Переменные окружения

| Переменная     | Значение по умолчанию                                     |
| -------------- | --------------------------------------------------------- |
| `DATABASE_URL` | `postgres://postgres:postgres@localhost:5432/schedule`    |
| `PORT`         | `8080`                                                    |

## API

| Метод  | Путь            | Тело запроса                                                                                                                                | Успех           | Ошибки   |
| ------ | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------- | --------------- | -------- |
| GET    | /groups         | —                                                                                                                                           | 200, массив     | 500      |
| GET    | /teachers       | —                                                                                                                                           | 200, массив     | 500      |
| GET    | /subjects       | —                                                                                                                                           | 200, массив     | 500      |
| GET    | /lessons        | —                                                                                                                                           | 200, массив     | 500      |
| POST   | /lessons        | `{"group_id":1,"teacher_id":1,"subject_id":1,"room":"ауд. 410","starts_at":"2026-09-28T09:00:00+05:00","ends_at":"2026-09-28T10:30:00+05:00","status":"planned"}` | 201, объект     | 400, 500 |
| DELETE | /lessons/{id}   | —                                                                                                                                           | 204             | 400, 404, 500 |

### Объект Group

```json
{ "id": 1, "name": "ИС-123/9", "year": 2023 }
```

### Объект Teacher

```json
{ "id": 1, "full_name": "Самарин Игорь Владимирович", "email": "samarin@mail.ru" }
```

### Объект Subject

```json
{ "id": 1, "name": "Базы данных" }
```

### Объект Lesson

```json
{
  "id": 1,
  "group_id": 1,
  "teacher_id": 1,
  "subject_id": 1,
  "room": "ауд. 410",
  "starts_at": "2026-09-28T09:00:00+05:00",
  "ends_at": "2026-09-28T10:30:00+05:00",
  "status": "planned",
  "created_at": "2026-09-21T09:38:37+05:00"
}
```

### Статусы занятия

| Значение    | Смысл          |
| ----------- | -------------- |
| `planned`   | запланировано  |
| `done`      | проведено      |
| `cancelled` | отменено       |

Если в `POST /lessons` поле `status` не передано — подставляется `planned`.

### Коды ошибок

| Код   | Когда                                                         |
| ----- | ------------------------------------------------------------- |
| `400` | невалидный JSON, `id` не число, некорректные данные занятия   |
| `404` | объект не найден                                              |
| `500` | ошибка базы данных                                            |

Тексты ошибок возвращаются как обычный текст (не JSON):

```text
Некорректный JSON
Ошибка создания занятия
```

## Структура проекта

| Файл              | Что внутри                                    |
| ----------------- | --------------------------------------------- |
| `main.go`         | запуск сервера, подключение к базе, маршруты  |
| `handlers.go`     | HTTP-хендлеры                                 |
| `store.go`        | SQL-запросы, работа с базой                   |
| `model.go`        | структуры данных (`Group`, `Teacher`, …)      |
| `schema.sql`      | схема таблиц                                  |
| `seed.sql`        | тестовые данные                               |
| `frontend/index.html` | страница, которая ходит в API             |

## Схема базы данных

```text
groups ──┐
         │
teachers ┼──< lessons >── subjects
         │
```

- `groups` — учебные группы
- `teachers` — преподаватели
- `subjects` — предметы
- `lessons` — занятия; ссылается на группы, преподавателей и предметы

## Роли в команде

| Роль              | Что делает                                                     |
| ----------------- | -------------------------------------------------------------- |
| Архитектор данных | схема БД, тестовые данные, контракт API, фронт                 |
| Бэкендер          | SQL-запросы, хендлеры, маршруты, подключение к базе             |

## Проверка

```bash
# список занятий
curl -i localhost:8080/lessons

# создать занятие
curl -i -X POST localhost:8080/lessons \
  -H 'Content-Type: application/json' \
  -d '{"group_id":1,"teacher_id":1,"subject_id":1,"room":"ауд. 500","starts_at":"2026-10-01T09:00:00+05:00","ends_at":"2026-10-01T10:30:00+05:00"}'

# удалить занятие
curl -i -X DELETE localhost:8080/lessons/1
```
